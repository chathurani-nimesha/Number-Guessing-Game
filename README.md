# 🎯 Number Guessing Game

A simple Number Guessing Game built using **HTML, CSS, and JavaScript**.

## Features

- 🎲 Random number between 1 and 100
- 🔢 Enter your guess
- ⬆️ Get a "Too Low" hint
- ⬇️ Get a "Too High" hint
- 🎉 Success message when you guess correctly
- 🔄 Start a new game
- 📊 Count the number of attempts
- 🔔 SweetAlert2 alerts

## Technologies

- HTML
- CSS
- JavaScript
- SweetAlert2

## How to Play

1. Enter a number between **1 and 100**.
2. Click **Guess**.
3. Follow the hints.
4. Try until you find the correct number.
5. Click **New Game** to play again.
